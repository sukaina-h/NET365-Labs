NET 365 - Advanced Networking Labs
This repository serves as a centralized collection for all labs completed during the NET 365 Advanced Networking course.

The labs focus on practical configuration, troubleshooting, and analysis of various network protocols using Cisco Packet Tracer, including:

Routing Protocols: OSPF, EIGRP, BGP

Switching: VLANs, Trunking, Spanning Tree Protocol (STP)

Security: ACLs, NAT

WAN Technologies

Each lab subdirectory contains:

EIGRPConfiguration.md: A detailed write-up outlining the lab objectives, step-by-step configuration, verification commands, and analysis of the results.

Lab.pkt: The final, completed Packet Tracer file used for implementation and testing.
